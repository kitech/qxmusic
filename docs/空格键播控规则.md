# 空格键播控规则（qlmusic / qskmusic 共用）

状态：生效
适用范围：qlmusic（Qt Widgets，含 Qt3/Qt4 双构建）与 qskmusic（QSkinny）

## 语义（按状态定，不猜意图）

| 当前状态 | 空格行为 |
|---|---|
| 焦点在文本输入且**内容非空** | 输入空格（放行，不播控） |
| 焦点在文本输入但**内容为空/仅空白** | 播放/暂停（且不插入空格） |
| 其他任意焦点（含播放按钮/空白/无焦点） | 播放/暂停 |
| 有 modal 弹层打开（菜单/队列/歌词） | 交给弹层，不播控 |

## 配套规则

1. 搜索框首字符禁止为空格：输入时 lstrip 前导空格。
2. 焦点生命周期：提交搜索 / 点击非输入区域 / Esc / 页面返回 → 立即清除输入焦点
   （Qt Quick 点击空白默认不清 activeFocusItem，必须显式处理）。
3. 页面打开不自动聚焦输入框（要输入必须用户先点它 = 明确意图）。
4. 媒体键 MediaTogglePlayPause 永远生效（输入中亦可播控，无歧义通道）。

## 实现位置

- qlmusic：`src/mainwindow.cpp` 应用级 eventFilter（原仅“输入框豁免”）
  + `qlcomp/searchline.cpp`（lstrip 首空格、回车后清焦点）
- qskmusic：`src/main.cpp` GlobalKeyFilter（Space/媒体键/焦点释放/返回键合一）

## 变更史

- 2026-11-11：确立本规则（qlmusic 原实现只有“输入框全豁免”，
  导致焦点残留时空格永久失效；空框空格=播控 + 首字符非空格两条为新增）。
